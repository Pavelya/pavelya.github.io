# pavelya.github.io

The top of Pavelya's GitHub Pages address. It holds one file:

- `app-ads.txt`: the AdMob account allowed to sell ads in Pinfold. AdMob reads it at
  `https://pavelya.github.io/app-ads.txt`, the root of the website named in Pinfold's Google Play
  listing. AdMob shows the line under Apps > app-ads.txt.

Pinfold itself, its website and its privacy policy live in
[Pavelya/dots](https://github.com/Pavelya/dots) and at `https://pavelya.github.io/dots/`.
